# Recorte de referência Samsung

Esta pasta contém somente quatro arquivos de referência anteriores a este índice: instruções do delta HZA6, um Makefile de DTS e dois arquivos Mali. **Não contém o Kernel.tar.gz completo nem os 34 arquivos do delta**, e não é uma árvore compilável de kernel.

Origem, hashes do pacote completo anteriormente analisado, aplicação do delta e drivers consultados estão em [docs/samsung-reference.md](../docs/samsung-reference.md). Não inferir que os arquivos isolados aqui representam todo o firmware HZC2 ou o kernel efetivamente em execução.

Os READMEs anexados novamente foram lidos e seus hashes registrados na documentação, sem duplicar o pacote-fonte no Git. Para a próxima análise do carregador, a prioridade é o pacote **BL HZC2**, não outra cópia desses READMEs.
